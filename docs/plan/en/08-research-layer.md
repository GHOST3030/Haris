# Phase 8 — Security Research Layer (advanced, optional)

**Goal:** Turn the project from a "scanning tool" into a genuine cybersecurity research project.

## Tasks
- Behavioral indicators (unusual usage patterns).
- Application reputation (aggregated across users, if a backend exists).
- Deeper certificate analysis (signing certificate comparison).
- Component analysis (dangerous exported Services, Receivers, Providers, Activities).
- Basic anomaly detection (simple rules first, before considering any ML).
