# المرحلة 8 — Security Research Layer (متقدم، اختياري)

**الهدف:** تحويل المشروع من "أداة فحص" إلى مشروع بحثي حقيقي في الأمن السيبراني.

## المهام
- Behavioral indicators (أنماط استخدام غير معتادة).
- Application reputation (بناءً على بيانات مجمّعة من عدة مستخدمين، إن وُجد Backend).
- Certificate analysis أعمق (signing certificate comparison).
- Component analysis (Services, Receivers, Providers, Activities المصدَّرة بشكل خطير).
- Anomaly detection مبدئي (قواعد بسيطة أولًا، قبل التفكير بأي ML).
