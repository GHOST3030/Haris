# مهام المرحلة 6 — Network Security + Privacy Center

## Network Security Module
- [ ] قراءة حالة Wi-Fi الحالية (SSID، نوع التشفير إن أمكن) عبر `WifiManager`.
- [ ] فحص وجود اتصال VPN فعّال عبر `ConnectivityManager` / `NetworkCapabilities`.
- [ ] فحص إعداد Private DNS الحالي.
- [ ] محاولة اكتشاف Proxy مُعدّ على مستوى النظام.
- [ ] قراءة/تقييم Network Security Config الخاص بالتطبيق نفسه (إن وُجد).
- [ ] فحص إن كانت هناك اتصالات Cleartext (HTTP غير مشفر) محتملة على مستوى إعدادات التطبيق.
- [ ] تجميع النتائج في `data class NetworkSecuritySignal`.
- [ ] كتابة نصوص توضيحية محايدة (بدون ادعاء كشف MITM الكامل).

## Privacy Center — الاستخدام الحديث
- [ ] استخدام `AppOpsManager` لمعرفة آخر وقت استخدام صلاحية حساسة (حيث يدعمه إصدار Android).
- [ ] عرض "آخر استخدام" بجانب كل تطبيق في القائمة (إن توفرت البيانات).
- [ ] التعامل مع القيود على الأجهزة/الإصدارات التي لا تدعم هذه الميزة بأمان (fallback بدون كسر التطبيق).
