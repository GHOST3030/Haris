# مهام المرحلة 8 — Security Research Layer (متقدم، اختياري)

## Behavioral Indicators
- [ ] تحديد قائمة أنماط سلوكية أولية تستحق المراقبة (مثلاً: تطبيق جديد يطلب صلاحيات كثيرة فجأة).
- [ ] بناء آلية لمقارنة سلوك التطبيق الحالي مع سلوكه في فحوصات سابقة (عبر Scan History).
- [ ] تصميم إشارة `BehavioralAnomaly` جديدة تُضاف إلى Risk Engine.

## Application Reputation
- [ ] تصميم آلية لتجميع بيانات مجهولة الهوية من عدة مستخدمين (عبر Backend) حول تطبيق معيّن.
- [ ] حساب "درجة سُمعة" أولية بناءً على عدد المستخدمين الذين أبلغوا عن مشاكل مع تطبيق معيّن.
- [ ] دمج درجة السمعة كإشارة إضافية في Risk Engine.

## Certificate Analysis
- [ ] استخراج Signing certificate لكل تطبيق مثبت.
- [ ] مقارنة الشهادة بقاعدة بيانات شهادات معروفة (موثوقة/غير موثوقة).
- [ ] اكتشاف حالات "نفس اسم التطبيق لكن شهادة مختلفة" (مؤشر انتحال محتمل).

## Component Analysis
- [ ] استخراج قائمة Services المُصدَّرة (exported) لكل تطبيق.
- [ ] استخراج قائمة Broadcast Receivers المُصدَّرة.
- [ ] استخراج قائمة Content Providers المُصدَّرة.
- [ ] استخراج قائمة Activities المُصدَّرة بدون حماية صلاحيات.
- [ ] تحديد معايير أولية لتصنيف هذه المكونات كخطيرة (exported + بدون permission محدد).

## Anomaly Detection (قواعد بسيطة أولًا)
- [ ] تعريف مجموعة قواعد بسيطة (rule-based) للكشف عن سلوك غير معتاد، دون أي ML في البداية.
- [ ] اختبار القواعد على بيانات حقيقية ومقارنة النتائج يدويًا.
- [ ] توثيق كل قاعدة ومبررها بوضوح.

## معيار إنهاء المرحلة
- [ ] دمج نتائج الأربع أقسام أعلاه (بشكل تدريجي، قسم في كل مرة) في تقرير الفحص النهائي، مع إمكانية تفعيل/تعطيل كل قسم بشكل مستقل.
